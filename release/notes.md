账号探测 v0.1.2

- 插件 ID 改为 `milesians.cpr-turnstate`，发布者改为 `milesians`
- 默认模型：ModelTrace `gpt-6.1-sol`，测票 `gpt-6-luna`；已有账号选择继续保留，空模型使用对应方法的默认值
- 每个账号可独立配置自动探测开关、模型和间隔；立即探测弹窗切换方法时分别保留模型选择
- 列表新增勾选、按当前筛选全选和批量配置（每批最多 200 个账号），可统一修改模型、开关、间隔，也可保持部分项目原值；整批校验后一次保存，保存不触发立即探测

**安装说明：** CPR 把新 ID 视为独立插件，不能直接从旧 `ezou.account-probe` 实例切换版本。请先停用旧实例，再从 GitHub 来源 `Milesians/cpr-turnstate` 安装 v0.1.2；旧设置和历史仍保留在旧实例，不会自动迁移。

要求 Codex Proxy RS `>=3.34.0, <4.0.0`，默认关闭真实探测。
